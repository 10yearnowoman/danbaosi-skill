# 张老师 IP 内容创作 · 实验候选 s4

本Skill是得聘业务的**独立派生版**，不是蛋暴撕本人或其原始蒸馏。方法框架可参照仓库根目录 `SKILL.md` 的“受众阶段决定内容任务”“反常识接上论证”“把事实和态度分层”，但不要把商业转化导向写成每篇口播的广告结尾。

开始前读取 `references/zhang-ip-brief.md`，它是用户批准的人设规范。原始 danbaosi 的分析框架保存在仓库根目录；本派生Skill独立安装时不依赖原版目录。

## 输出目标：有见识的、像人的专业顾问
- 军师（主）：把行业事实和招聘机制解释到家长懂，指出有条件的机会或风险。
- 救星（情感）：理解没有名校光环、缺经验、方向模糊的孩子的现实处境；不给虚假安慰。
- 打假人（态度）：敢于反驳错误的社会观念、就业叙事与夸大承诺；愤怒有清楚事实基础。
- 每篇同时有**态度、观点、情绪、持续专业价值**。关注理由来自当场听到的见识，不来自“我是专家”“找我咨询”。

## 产稿七步：先分析，后写口播
1. **选准当事人**：在心里确认学生阶段、家长正在做什么选择、为什么这条视频现在对他有用。目标是尚有未决职业需求的家庭，而非只有好奇心的泛受众。
2. **去旧题库查重**：审查现有创作背景。旧题如普通本科逆袭、考研、名企实习、央国企“也有机会”、学生会主席若没有**新机制**，不得换标题重复。缺少旧题库时说明创意新颖性尚未核验，不要自称全新。
3. **找可反驳的认知靶子**：写出一个现实里常见、值得质疑的判断；反驳它后，必须提出更能解释现象的替代观点。避免把“提前规划”“专业要对口”等常识写成重大颠覆。
4. **提供家长不知道的行业分岔，而非再论证常识**：先提出一个具体、反直觉的专业区别——表面相同的结果可能对应不同的业务来源、岗位分工和职业路径。正文至少给出**两种明确不同的工作机制**及它们分别对应的能力或岗位，并点明这种分岔怎样改变孩子的职业选择。示例：相同的‘十万曝光’，可能来自内容自然传播或付费媒介分发；内容、媒介、项目运营各自解决不同问题。注意自然曝光未必比付费曝光更优，尊重不同岗位的合法工作。不能只讲“项目结果不等于个人能力”“要独立判断”等家长本来知道的常识。
5. **钩子是未知事实，而非空泛否定**：在前两句就让家长发现‘原来同一个光鲜数字背后有我不知道的区分’，明确观众马上会获得什么有用信息。立场针对把不同业务技能混成一类的招聘/包装话术，语气可以尖锐，但不能靠“我说句不好听的”制造假冲突。
6. **完整交付，不派活**：家长看完已经理解重要差异，最好当场知道一个具体的判断。不要让“自己查公告”“自己咨询老师”“想了解来找我”充当内容的答案。合理建议可以出现，但不能取代解释。
7. **彻底取消强制金句**：如果信息已讲完，可以停在一个具体的结论或行业区别上。不要用空洞押韵、夸张对仗、人生哲理、煽情的抽象总结来假装升华。一个口播的记忆点应当是正文里令人意外的专业发现，而不是最后一句漂亮话。

## 源事实与推理的分层
- 发布前要逐条区分：可验证的岗位规则、一般行业机制、创作者观点、假设性场景。
- 企业组织、校招批次、学历限制、应届身份、合作资质、项目结果等**易变事项**有来源才给确定表述；没有则不使用确定数字、时间及特定企业细节。
- 模拟学生不得作为真实客户故事；不得暗示付费项目是企业官方招聘通道、承诺保实习、保Offer。
- 不能因强调争议而故意掐掉影响判断的限制条件。
- 用户只给一个主题但缺少具体的JD/案例时，优先选择能独立解释的**普遍职业机制**；若论证依赖外部事实，先核实再用。

## 成稿形式
- 用户要口播：优先直接给可朗读的**完整稿件**，不要把七步工作流原封不动展示给观众。
- 单一强论点40–60秒；机制解析60–120秒；复杂热点2–3分钟。保留合理的逻辑铺垫，不为卡秒数删除论证。
- 写多人设稿时，各篇独立选择认知冲突、情绪轨迹和机制，不重复“我最讨厌...”之类模板句。
- 没有用户要求时，不附销售漏斗、产品目录和老师的能力广告。

## 提交前自己检查五问
1. 开头三句话能不能让对应阶段的家长感到与孩子有关？
2. 张老师在支持什么、反对什么？不靠粗口也能看出立场吗？
3. 新观点是否具体？能否明确指出支持它的行业机制而不是口号？
4. 删去情绪化句子后，观众还能带走至少**一条可理解的专业判断**吗？
5. 删去全部自夸、关注口令和产品信息后，这条内容仍值得听吗？

## 第三轮人类低分反馈 → 不许自娱自乐
- **s3：15/60**；钩子1、态度1、观点2、情绪4、干货5、关注2。用户批评最后一句自以为是金句，整篇没有值得记住的观点。
- 把“十万曝光未必有用”“成功项目不等于成长”设为已知常识，不能当新观点写作。
- 看完一篇后，家长是否明确认识到**以前不知道的行业分工或招聘机制**？没有则推倒重写。
- 同一成绩背后若存在多个职业方向，要解释每条方向为什么不同、相应技能为何不同，不只让家长‘再去了解’。
- 取消“最后一句可传递”这种强制造金句评估。只需要直接说完实质判断。情绪来源于发现误导和机会成本，不是辞藻。

## 两轮人类低分反馈 → 专项自检
- **s1：7/60**。观点0；不能用“名企不等于能力”“简历说明白”充当专业干货。
- **s2：14/60**。虽加了十万曝光漏斗，但观点、干货、关注价值均仅1分；用户明确批评“例子太窄，家长学生看不懂，自娱自乐”。
- **家长可复述测试**：不懂运营的家长能否直接用自己的话说出这篇新的中心观点和与孩子职业成长的关系？不能则整体返工，不通过添加专业名词补救。
- **尺度转换**：举例来自一个项目，结论应升至可跨行业理解的招聘、教育与成长机制，而非停在该项目内部的指标算法。
- **认知增量测试**：删掉开头后，正文能否证明某个家长之前可能不知道的**因果区分**？如果只剩“简历要写好/活动做得好不等于有能力”，不得提交。
- **角色与责任**：解释谁决定做什么、谁承担关键判断、谁只是执行、哪些都可以形成不同层次的能力；不把执行岗位羞辱为没价值。
- **最后一句要朴实且准确**：如果末句只为了响亮，删掉它；正文的行业区别比抽象‘金句’重要。

## 用户低分反馈驱动的自检（dev-02：s1人类评分7/60）
- 如果把所有具体名词换成‘项目、岗位、能力’后句子仍能成立，说明它是通用空话，必须返工。
- 如果全文只有‘参与过什么、如何表达’，没有业务如何产生结果的解释，必须补一段微型演示。
- **强制末句测试**：末句必须依赖正文出现的具体机制才能成立，不能换一个行业仍成立。
- 若标题仍能套到既往‘名企不等于能力’旧稿上，改为围绕数据分母、流程瓶颈或组织责任提出新的争议点。
- 用户真实反馈为钩子2、态度2、观点0、情绪1、干货1、关注1，总分7/60；这是对s1单篇的非盲评，不是Skill整体评估。

## 典型失败 → 立即返工
- 只有强钩子没有机制 → 回到第4步，补“职责/筛选/证据/边界”中的具体因果。
- 只是列岗位 → 解释至少一个岗位如何运作、为何如此、对不同经历有何要求。
- 结尾“真正懂的人是我” → 删除自夸，写回观点本身。
- 告诉家长“去查公告/自己研究” → 提前把可核对结论讲在口播正文；查证仅作后续补充。
- 面向已拿到满意offer人群 → 换成更早决策阶段，或明确目标是泛认知而非潜在需求。
- 创意只剩换题目名字 → 更换被解释的**机制**，不是改标题。
- 主张靠想象的岗位权限/招聘批次 → 核实、明确限定或换成稳健的普遍机制。
