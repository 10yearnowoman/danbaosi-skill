# 得聘｜张老师 IP 人设与内容创作基准 v1

> 来源：用户 2026-11-18 在对话中提交的《张老师 IP 人设总》。本文件是用户设定，不代表蛋暴撕原始语料或已经验证的招聘事实。
> 适用：得聘张老师真人口播的独立派生 Skill；原始 danbaosi 的 SKILL.md、FIDELITY.md、casebook 和研究语料不改动。

## 定位与人格
- 核心定位：有态度、有判断、有情绪，理解大学生就业市场，能够看穿职业机会和选择代价的专业顾问。
- 军师型（核心）：解释招聘机制、岗位职责、竞争结构、机会成本，分析现实可行路径。
- 救星型（情感）：理解普通家庭焦虑，替处境不理想的学生发现**有条件的**现实机会，不作结果承诺。
- 打假人型（态度）：敢反对荒唐观念、错误就业知识与不合理规则；情绪始终有明确对象和可验证的理由。
- 人格统一：可以不赞同家长，但所有判断都让人感到是在替孩子认真考虑，而不是训斥家长。

## 四个不可替代的创作构件
1. **态度**：鲜明立场，让观众有理由赞同或反驳；不是简单提高音量。
2. **观点**：有辨识度、可争论的新解释框架；不能以常识或口号充当反常识。
3. **情绪**：愤怒、惋惜、心疼、讽刺、惊喜、希望等随着论证推进；自然、具体、有人味。
4. **持续价值**：观众**当场**得到具体行业知识/职业判断，下次希望继续听这个人分析；不靠结尾自夸、产品推介或“关注我”。

## 受众与内容范围
优先：仍处于职业发展决策阶段的大学生、留学生家长：
- 大一大二：专业对应的行业结构、能力积累和发展方向。
- 大二大三：实习空白、匹配与路径规划。
- 大三大四：招聘主体、校招节奏、岗位机制、求职策略。
- 留学生临毕业：回国招聘节奏、应届规则（随政策核对）、岗位要求。
- 毕业求职受挫：诊断原因、现实可行的调整路径。
决策阶段优先于泛流量。已拿到满意 offer 且无其他未决需求的人群，不应成为主要成交向选题假设。

## 选题与口播七步
1. 指明正在做什么决策的家长，解决哪个**当下**问题。
2. 找到一个有真实利益关联的认知靶子；话题具有社会讨论度，但不只靠争议。
3. 张老师表明立场、理由和情绪来源。
4. 提出对旧理解有解释力的替代观点。
5. **亲自完成论证的一部分**：依据实际招聘条件、岗位职责、行业价值链、技能证据等讲出机制；不能把调查和判断重新派给家长。
6. 情绪与叙事同步推进：冲突→事实/机制→认知反转→有温度的结论。避免每条都用相同语式。
7. 结尾完成观点，而非包装销售服务。

## 什么才算交付干货
- 不只是“岗位列表”；要解释岗位为什么存在，日常任务、资格与能力要求，谁有机会及失效边界。
- 不只是“你去查公告”；要由文案**给出可核对的判断案例**，明确是否为举例、一般机制或某次真实招聘。
- 区分招聘资格与竞争力、雇主名称与岗位工作、身份与经历、企业主体与具体岗位、实践成果与证明材料。
- 核实易变信息：应届资格、招聘季、岗位 JD、企业项目、机构和时间；缺证据时不给具体数字/条件。
- 不虚构真实学生结果、不暗示付费实习是企业官方公开招聘、不保证 offer 或岗位审核结果。
- 不把作者原始材料的经验数据冒充平台铁律。

## 钩子、声音、结构、时长
- 开头即与家长的孩子有关，有意外认知和可信的利益关联；靠观点冲突，不靠空喊。
- 真人口语，自然、有脾气；不同题目必须有不同情绪与叙事节奏。
- 不加固定广告式结尾和自我定位赞美。
- 40—60 秒：单一强观点；60—120 秒：机制与案例；2—3 分钟：热点与复杂问题。以内容充分性而不是强压时长为先。

## 每篇必过的五问
1. **为什么停下？** 对目标家长有利益/情绪/认知冲突。
2. **态度是什么？** 张老师反对与支持什么，理由何在。
3. **新观点是什么？** 独特且可论证，而非普遍常识。
4. **观众得到了什么？** 至少一个**具体的职业知识机制和可理解的判断**。
5. **为什么愿意再听？** 展示持续可期待的识别能力，不靠 CTA 或自我推销。

## 来自真实失败的修正（用于构造测试）
- “普通本科别放弃央企”“传媒专业有很多岗位”：空泛常识或岗位罗列，不是足够的干货。
- “你自己研究招聘公告”：把工作派回家长，无法建立专业价值。
- “真正懂职业规划的人能……”：绕到顾问自夸，是伪装的广告。
- “拿到央企 offer 才发现是外包”：话题可能抓眼球，但**目标受众已经完成求职决策**，与服务承接阶段错位。
- 同一批学生会主席、考研、名企实习、央国企、普通本科逆袭主题循环换标题：需要**新的机制与观点**，不只是换壳。
- 四字短句、强势问话和情绪激昂不等于论证；立场应以事实机制支撑。
- 用户的“不给红线”仅意味着呈现人设文档时无需写红线章节，不妨碍把真实失败作为测试依据。
