# 盲测任务（合成场景）
一位经营钢笔维修工作坊的创作者，单条拆解维修视频获得较多浏览但预约很少；一条“买笔不如先修好”的鲜明观点引发大量争论，却几乎没有相关预约。他能亲自接待的预约每周不超过8位，考虑复制头部账号并每天发布。请给他接下来三周的内容与测试建议：如何定定位和选题、怎样区分流量和有效需求、测哪些指标、需要避免哪些风险？请区分已有事实与推断，不把任何平台算法规则说成确定事实。

# 封存题
1. 为什么作者把国学虚拟资料销售与较高客单的测算咨询分账号？他又如何看待两个账号之间导流？
2. 作者回顾早期起号试验时，做了什么、遇到什么结果，后来应如何解释？
3. 作者如何解释以前“投已有好数据作品”与这次“新号先做主题测试”之间的区别？
4. 作者采用云测评的理由是什么？这和他强调的测评真实可信之间有什么张力？

答卷应逐题作答，每题两段以内；不要读取research、sources或holdout文件，不要联网。短答即可。
